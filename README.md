# Serpantinum_Atrixx_Edition

Serpantinum_Atrixx_Edition — доработанная редакция Serpantinum, созданная Atrixx_Studio для тех, кому важны скорость работы, наглядные графические настройки и минимум лишних действий в терминале без потери совместимости с обновлениями оригинального проекта.
Ключевые особенности

Меньше терминала — больше графики: удобные меню, быстрые переключатели и графические настройки для повседневных задач, чтобы не лезть в конфиги вручную при каждом изменении.
Улучшенное быстродействие: оптимизированы автозапуск, фоновые процессы и визуальные эффекты для более отзывчивой работы системы — в том числе на менее мощном железе.
Фишки Atrixx_Studio: фирменные пресеты, быстрые сценарии и доработки рабочего процесса под стиль Atrixx_Studio.
Поддержка обновлений Serpantinum: структура изменений выстроена так, чтобы свежие улучшения и фиксы из оригинального Serpantinum можно было аккуратно переносить и применять без полной пересборки окружения с нуля.

Зачем эта редакция?
Оригинальный Serpantinum задаёт сильную базу, но иногда хочется быстрее менять параметры через интерфейс, не тратить время на ручные правки файлов и выжать максимум плавности. Serpantinum_Atrixx_Edition закрывает именно эти задачи, оставаясь на связи с апстримом.



Оверлей поверх [Serpantinum](https://github.com/ilyamiro/serpantinum). Код апстрима здесь **не копируется и не меняется**:
оригинал ставится и обновляется своим установщиком, Atrixx Edition лежит рядом и подключается через include.

## Установка
```bash
bash -c "$(curl -fsSL https://raw.githubusercontent.com/Lampam-mine/Serpantinum_Atrixx_Edition/main/install.sh)"
```
Не запускать от root. Если Serpantinum не найден, будет предложен его оригинальный установщик (он отправляет телеметрию — см. README апстрима).

## Команды
| команда | что делает |
|---|---|
| `atrixx update` | обновляет Atrixx, затем апстрим (в его установщике выберите «update»), затем переприменяет оверлей |
| `atrixx update --no-upstream` | только Atrixx |
| `atrixx reapply` | переприменить оверлей (после ручного обновления апстрима) |
| `atrixx enable/disable <модуль>` | включить/выключить модуль (`core`, `perf-lite`) |
| `atrixx status`, `atrixx doctor` | состояние и диагностика |
| `atrixx uninstall` | снять оверлей; апстрим не затрагивается |

## Правила, благодаря которым обновления не конфликтуют
1. Модули пишут только в `~/.config/atrixx`, `~/.local/share/atrixx`, `~/.local/state/atrixx` и `~/.local/bin/atrixx`.
2. В пользовательские конфиги композитора добавляется один блок между маркерами `# >>> atrixx:core >>>`; до первого изменения делается резервная копия оригинала (`~/.local/state/atrixx/backups`).
3. Все модули идемпотентны: `reapply` можно запускать сколько угодно раз.
4. Порядок обновления всегда: Atrixx → апстрим → оверлей. Оверлей всегда применяется последним.
5. `compat.conf` хранит ветку апстрима, на которой оверлей проверен. Если вышла новая — будет предупреждение и вопрос. Workflow `upstream-watch` создаёт issue, когда у автора выходит новый релиз.

## Свои настройки
Кладите файлы в `~/.config/atrixx/hypr.d/user-*.conf` (или `sway.d/`) — модули их не перезаписывают.

## Новый модуль
Создайте `modules/<имя>/module.sh` с функциями `mod_desc`, `mod_apply`, `mod_revert`. Пишите только в `$ATRIXX_CONF`.

## Ещё не проверено
Niri и Mango (подключение вручную), путь установки и формат версии апстрима, взаимодействие `perf-lite` с эффектами самой оболочки.
