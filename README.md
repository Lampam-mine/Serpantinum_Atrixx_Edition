# Serpantinum_Atrixx_Edition

**Serpantinum_Atrixx_Edition** — доработанная редакция **Serpantinum**, созданная **Atrixx_Studio** для тех, кому важны скорость работы, наглядные графические настройки и минимум лишних действий в терминале без потери совместимости с обновлениями оригинального проекта.

## Ключевые особенности

- **Меньше терминала — больше графики:** удобные меню, быстрые переключатели и графические настройки для повседневных задач, чтобы не лезть в конфиги вручную при каждом изменении.
- **Улучшенное быстродействие:** оптимизированы автозапуск, фоновые процессы и визуальные эффекты для более отзывчивой работы системы — в том числе на менее мощном железе.
- **Фишки Atrixx_Studio:** фирменные пресеты, быстрые сценарии и доработки рабочего процесса под стиль Atrixx_Studio.
- **Поддержка обновлений Serpantinum:** структура изменений выстроена так, чтобы свежие улучшения и фиксы из оригинального Serpantinum можно было аккуратно переносить и применять без полной пересборки окружения с нуля.

## Зачем эта редакция?

Оригинальный **Serpantinum** задаёт сильную базу, но иногда хочется быстрее менять параметры через интерфейс, не тратить время на ручные правки файлов и выжать максимум плавности. **Serpantinum_Atrixx_Edition** закрывает именно эти задачи, оставаясь на связи с апстримом.
